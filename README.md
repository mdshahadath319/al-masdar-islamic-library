## Current project information

The live website provides a digital book library, online PDF reading, book borrowing, and user account functionality. The documented subject categories include Tafsir, Hadith, and Fiqh.

The website uses a PHP application with an SQL database. The Telegram bot has separate data and webhook components; those components are not the website's backend.

For current service availability and the live experience, visit the [official website](https://al-masdar.free.nf). Repository documentation may not always reflect changes immediately.

## Project status

**Website status: Live and operational** (last project status recorded: November 2026).

A native Android application and a Telegram Mini App have been discussed as future possibilities. They should not be treated as released products unless a dated public announcement says otherwise.
