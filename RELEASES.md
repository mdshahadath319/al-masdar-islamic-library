# Releases and Announcements

This page indexes public project release announcements.

## Release policy

A release entry should be created when a meaningful change is made available to users or when an official project milestone is announced.

Each release announcement should state:

- Release title and date
- A concise summary
- New features or improvements
- Fixes and known limitations, where relevant
- Whether the change affects the live website
- Links to relevant documentation or announcements

Do not publish private deployment details, credentials, database exports, or security-sensitive information.
