# Security Policy

Al-Masdar Islamic Library takes reports about potential security vulnerabilities seriously.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details, credentials, personal data, or attack instructions in a public GitHub issue or discussion.

Use a private contact channel published on the official website, if one is available. If no private security contact is published, contact the project owner through an established private channel before sharing sensitive technical details.

**Official website:** https://al-masdar.free.nf

This repository does not currently publish a dedicated security-response email address or a guaranteed response-time commitment.

## What to include

When contacting the project privately, provide only the information necessary to understand and reproduce the issue safely:

- A brief description of the suspected issue
- The affected public page or feature
- Potential impact
- Minimal reproduction steps, avoiding access to other users' data
- Your preferred method of follow-up

Do not access, modify, download, or disclose another person's data. Do not disrupt the live service.

## Public disclosure

Please allow the project owner a reasonable opportunity to assess and address a report before publicly disclosing technical details.

## Scope

This policy applies to the publicly accessible Al-Masdar Islamic Library service and its related public-facing components. It does not authorize testing against third-party systems or infrastructure.
