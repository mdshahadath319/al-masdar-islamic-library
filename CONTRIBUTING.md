# Contributing

Thank you for helping improve the public documentation for Al-Masdar Islamic Library.

## Scope

This is a documentation-only repository. Contributions should focus on:

- Correcting documentation errors
- Improving clarity and navigation
- Suggesting user-guide or FAQ topics
- Reporting broken documentation links
- Proposing improvements to public project information

Source code, database files, credentials, server configuration, and private operational material are outside this repository's scope.

## Before submitting

1. Search existing issues and discussions to avoid duplicates.
2. Keep suggestions specific and factual.
3. Include a relevant page or section when reporting an error.
4. Do not include private information or security-sensitive details.

## Pull requests

A documentation pull request should explain:

- What document is being changed
- Why the change is needed
- Which statements have been verified
- Whether any dates or status labels need review

Do not describe proposed or unverified features as released.

## Community conduct

Be respectful, constructive, and focused on the project. Harassment, spam, personal attacks, and disclosure of private information are not appropriate.

The project owner may review, request changes to, or decline contributions.
