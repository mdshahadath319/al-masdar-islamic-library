# About Al-Masdar Islamic Library

## Overview

Al-Masdar Islamic Library is a digital Islamic library project established in 2026. The project is based in Bholahat, Rajshahi, Bangladesh.

**Official website:** https://al-masdar.free.nf

The project aims to make its digital Islamic book collection accessible through an online library experience.

## Website and platform

The website is a PHP-based application backed by an SQL database. Its website database is the source of the website's library and account functionality.

The Telegram bot is a separate component. Its JSON data and webhook are not the website application's backend.

## Publicly documented areas

- Digital Islamic book collection
- Online PDF reading
- Book borrowing
- User accounts
- Subject categories including Tafsir, Hadith, and Fiqh

See [Features](FEATURES.md) for the current documented feature summary.

## Future possibilities

A native Android application and a Telegram Mini App have been discussed as possible future extensions. These are planning topics, not claims that those applications are currently available.
