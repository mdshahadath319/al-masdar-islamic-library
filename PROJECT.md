# Project Overview

## Al-Masdar Islamic Library

Al-Masdar Islamic Library is a digital library project based in Bholahat, Rajshahi, Bangladesh. It was established in 2026 to support access to selected Islamic books and encourage sound Islamic learning.

## Available Website Capabilities

- Book discovery and search.
- Category-based book browsing.
- Online PDF reading for signed-in users.
- User account management.
- PDF reading history.
- Physical book borrowing requests and administration.
- SMS notifications for borrowing-related and other relevant library information.

The physical library is under development. At present, the online PDF service is the operational library service.

## Telegram Integration

The official Telegram bot is [@AlMasdarLibraryBot](https://t.me/AlMasdarLibraryBot).

The bot supports book search, book details and access to the corresponding website PDF Reader page. It does not deliver PDF files directly through Telegram. Users must sign in to the website to read PDFs.

## Project Status and Maintenance

The website is live and operational, and users can access the features currently available on the platform.
