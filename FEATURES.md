# Features

This page summarizes capabilities documented for the Al-Masdar Islamic Library website.

**Official website:** https://al-masdar.free.nf

> Feature availability and behavior can change. The live website is the definitive place to check the current user experience.

## Website features

### Digital book library

Visitors can explore the digital Islamic book collection available through the website.

### Online PDF reading

The website provides PDF reading functionality for supported library books.

### Book borrowing

The website includes a book borrowing feature. Users should follow the instructions and conditions presented by the live service.

### User accounts

The website provides user account functionality.

## Subject categories

The documented library categories include:

- Tafsir
- Hadith
- Fiqh

The category list may expand as the catalog develops.

## Book identification

The project has used the book identification format `MIL/BK/CP`. This is recorded as project information; detailed identifier allocation rules are not specified in this document.

## Platform notes

The website is a PHP application backed by an SQL database. Telegram bot data and webhook components are separate from the website backend.
