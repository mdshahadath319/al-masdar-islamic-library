These items are exploratory. No release date or implementation commitment is implied.

## Roadmap status definitions

- **Completed:** Publicly available or completed and documented.
- **In progress:** Work has been publicly confirmed as underway.
- **Planned:** Approved for future work, but not yet released.
- **Under consideration:** An idea being evaluated; not an implementation commitment.
- **On hold:** Work has been paused.
- **Cancelled:** Work will not proceed.

Only change an item to **In progress** or **Completed** when there is a confirmed project update. Add dates and supporting release/update links whenever possible.
